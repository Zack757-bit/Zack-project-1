# Zack-project-1 : 
🍽️ Food Lover - Restaurant Website

A modern and responsive restaurant website built with HTML5 and CSS3.

📌 About The Project

Food Lover is a restaurant website designed with a clean and attractive interface to showcase the restaurant's food, special offers, daily meals, and gallery.

The project was created as a frontend web development project to practice building responsive websites using HTML and CSS.

✨ Features

- 🏠 Home section
- 📖 About Us section
- 🍽️ Food menu
- ⭐ Special offers
- ☀️ Daytime meals
- 🖼️ Food gallery
- 📞 Contact section
- 📱 Responsive design
- 🎨 Custom CSS styling
- 🖼️ Local images and icons
- 🔤 Google Fonts
- ⭐ Font Awesome icons

🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

🚀 Getting Started

Clone the repository

git clone https://github.com/Zack757-bit/food-lover-restaurant.git

Run the project

Open the project folder and launch "index.html" in your browser.

No additional installation is required.

📱 Responsive Design

The website is designed to provide a good experience across different screen sizes:

- 📱 Mobile
